# Employee Attrition Analysis & HR Analytics Dashboard

An end-to-end Machine Learning and Data Analytics project designed to identify factors driving employee turnover and predict attrition risks.

## Features
- **Exploratory Data Analysis (EDA):** Deep dive into salary, tenure, department, and work-life balance patterns.
- **Classification Modeling:** Benchmark models including Logistic Regression, Random Forest, and XGBoost with imbalanced data handling.
- **Interactive HR Dashboard:** Streamlit application with interactive Plotly visual KPIs.
